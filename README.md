# AdventureWorks Sales & Operations Dashboard

## Project Overview

This Power BI project is built on a subset of the **AdventureWorks** dataset and focuses on analyzing end-to-end sales and operations performance. The report provides actionable insights across **Manufacturing, Procurement, Transactions, and Routing**, enabling stakeholders to monitor efficiency, costs, delays, and product-level performance.

The dashboard is designed with a business-first approach, combining KPIs, trends, and comparisons to support operational and strategic decision-making.

---

## Report Pages

### 1. Manufacturing Insights

* Net Production and Accepted Units with year-over-year comparison
* Average Production Days and Delay Days
* Scrap Quantity analysis for top products
* Delayed days by product class and product
* Production quantity trends vs previous year
* Order, stock, and scrap flow over time

### 2. Procurement Insights

* Net Purchase Cost with YoY comparison
* Purchase cost trend over time
* Top products by purchase cost
* Rejection percentage and rejected quantity analysis
* Ordered vs received quantity comparison
* Quality issues trend by month

### 3. Transactions Insights

* Sales quantity and value trends
* Product-level and time-based performance analysis
* Comparative metrics to evaluate sales behavior over time

### 4. Routing Insights

* Routing and process-level performance metrics
* Delay and efficiency analysis across operations
* Identification of bottlenecks impacting production flow

---

## Data Model

* Multi-table relational model based on AdventureWorks
* Fact tables for production, procurement, and transactions
* Dimension tables for products, time, and classifications
* Clean relationships designed for scalable analysis

---

## Key Features

* Interactive slicers (Year, Product Class, Status)
* Dynamic KPIs with previous-year comparison
* YoY analysis and trend-based visuals
* Product-level drilldowns for root cause analysis
* Consistent layout and navigation across report pages

---

## Tools & Technologies

* **Power BI Desktop**
* **DAX** for calculated measures and KPIs
* **Power Query** for data transformation and modeling

---

## Use Case

This dashboard simulates a real-world enterprise reporting scenario where manufacturing, procurement, and sales data are analyzed together to improve operational efficiency, reduce delays, control costs, and identify high-impact products.
